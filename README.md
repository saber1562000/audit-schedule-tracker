# Audit Tracker

Audit scheduling, capacity tracking, and vendor management 
application for pharmaceutical and life sciences organisations.

## Features

- **Dashboard** — KPIs, demand tracking, donut charts, collapsible cards
- **Audit Management** — Full lifecycle tracking with timeline visualisation
- **Vendor Management** — Vendor records, risk scoring, qualification tracking
- **Forecast** — Interval-driven routine audit demand projection
- **Capacity** — CU-based workload tracking, regional comparison, distribution balance
- **Skills Matrix** — Team competency heatmap, gap analysis, auditor profiles
- **Calendar** — Auditor leave management with audit/travel day auto-population
- **Risk Heatmap** — Vendor priority scoring with narrative explanations
- **Closure Tracker** — Post-execution audit backlog monitoring
- **Data Quality** — Duplicate detection for audits and vendors

## Tech Stack

Plain HTML5, CSS3, and vanilla JavaScript. No frameworks, no build tools.
SheetJS for Excel import/export. localStorage for data persistence.

## Usage

Clone or download, then open `index.html` in a browser. No server required.
